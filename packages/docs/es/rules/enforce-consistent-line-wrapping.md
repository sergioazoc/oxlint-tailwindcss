# enforce-consistent-line-wrapping

> Warn when a class string exceeds the configured print width

## Opciones

| Option | Type |
|---|---|
| `printWidth` | number |
| `classesPerLine` | number |

## Valores por defecto

```json
{
  "printWidth": 80
}
```

## Auto-fix

- Esta regla **arregla automáticamente** (fixable: `whitespace`).
