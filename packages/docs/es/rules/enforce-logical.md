# enforce-logical

> Enforce logical (RTL-friendly) Tailwind CSS properties instead of physical ones

## Opciones

| Option | Type |
|---|---|
| `allowlist` | string[] |
| `direction` | `"inline"` \| `"block"` \| `"both"` |

## Valores por defecto

```json
{
  "allowlist": [],
  "direction": "both"
}
```

## Auto-fix

- Esta regla **arregla automáticamente** (fixable: `code`).
- Ofrece sugerencias adicionales en el editor.
