# enforce-physical

> Enforce physical Tailwind CSS properties instead of logical ones for consistency in LTR-only projects

## Options

| Option | Type |
|---|---|
| `allowlist` | string[] |
| `direction` | `"inline"` \| `"block"` \| `"both"` |

## Default values

```json
{
  "allowlist": [],
  "direction": "both"
}
```

## Auto-fix

- This rule is **auto-fixable** (`fixable: code`).
- It also offers editor suggestions for non-primary fix candidates.
