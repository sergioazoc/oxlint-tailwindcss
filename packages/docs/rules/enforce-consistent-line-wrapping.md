# enforce-consistent-line-wrapping

> Warn when a class string exceeds the configured print width

## Options

| Option | Type |
|---|---|
| `printWidth` | number |
| `classesPerLine` | number |

## Default values

```json
{
  "printWidth": 80
}
```

## Auto-fix

- This rule is **auto-fixable** (`fixable: whitespace`).
