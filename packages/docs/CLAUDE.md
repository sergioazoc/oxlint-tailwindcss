# CLAUDE.md — docs site

## Rule pages are generated — edit the source, not the output

`rules/<rule>.md` and `es/rules/<rule>.md` are generated by `scripts/generate-rules.ts` and
overwritten on every build/generate. Editing them directly is silently lost. Change the body via the
`_extras` partial — `rules/_extras/<rule>.md` (EN), `es/rules/_extras/<rule>.md` (ES) — then run
`pnpm -C packages/docs generate`. Mirror EN edits into ES (neutral tuteo, never voseo).

## Markdown is formatted by oxfmt (`generate` formats its own output)

All `.md` is formatted by oxfmt (`proseWrap: always`, so prose is wrapped at the print width — don't
hand-wrap, the formatter owns it). Two consequences here:

- The `generate` script runs `oxfmt --write` over the generated pages as its last step, so generated
  and source markdown stay consistent and `format:check` passes. Always regenerate via
  `pnpm -C packages/docs generate`, not the raw script.
- Fenced code blocks are **not** reformatted (`embeddedLanguageFormatting: off`) — example snippets
  (e.g. JSON config) stay exactly as written, so keep them copy-paste correct by hand.
