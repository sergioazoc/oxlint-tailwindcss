# enforce-physical

> Enforce physical Tailwind CSS properties instead of logical ones for consistency in LTR-only projects

## Opciones

| Option | Type |
|---|---|
| `allowlist` | string[] |
| `direction` | `"inline"` \| `"block"` \| `"both"` |

## Valores por defecto

```json
{
  "allowlist": [],
  "direction": "both"
}
```

## Auto-fix

- Esta regla **arregla automáticamente** (fixable: `code`).
- Ofrece sugerencias adicionales en el editor.
