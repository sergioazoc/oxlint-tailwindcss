# enforce-consistent-variable-syntax

> Enforce consistent CSS variable syntax: bg-[var(--color)] ↔ bg-(--color)

## Options

| Option | Type |
|---|---|
| `syntax` | `"shorthand"` \| `"explicit"` |

## Default values

```json
{
  "syntax": "shorthand"
}
```

## Auto-fix

- This rule is **auto-fixable** (`fixable: code`).
- It also offers editor suggestions for non-primary fix candidates.
